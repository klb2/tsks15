Tutor Prompts

The following is a suggestion for a prompt that creates a tutor for studying the contents of TSKS15.

The tutor uses the Socratic method, so it will ask questions to guide you to the solution and a better understanding of the topic. Try using it this way and do not ask for answers immediately. Some suggestions when responding to the tutor:

  • Take time to think before responding
  • Explain your reasoning, not just your answer
  • If you're unsure, say what you're thinking anyway

The following are some example prompts for using the tutor.

Goal Example Prompt
Concept help I'm confused about when the Cramér-Rao bound is attained. Can you help me reason through this?
Exercise help I'm deriving the LMMSE estimator. I've set up the orthogonality principle but I'm stuck on the next step.
Verify work Here's my derivation: [paste work]. Can you check if my reasoning is correct?
Exam prep Can you quiz me on Bayesian detection? Ask one question at a time.
Direct solution I've struggled for 20+ minutes. Please give me the complete solution. No questions.
